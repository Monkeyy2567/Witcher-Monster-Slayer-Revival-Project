# นักล่าอสูรแห่งเมือง (City Hunter)

ต้นแบบเกมล่ามอนสเตอร์บนแผนที่จริง ผสมแนว Witcher: Monster Slayer กับ Monster Hunter
ไฟล์เดียว (`index.html`) เปิดในเบราว์เซอร์ก็เล่นได้ ไม่ต้องติดตั้งอะไร ตัวละครเป็นอีโมจิทั้งหมด
และไม่ได้ใช้โค้ดหรือ asset จากเกม Witcher หรือโปรเจกต์ Revival ที่อยู่โฟลเดอร์อื่นใน repo นี้

## เล่นยังไง
- เปิด `index.html` ในเบราว์เซอร์ (ต้องต่ออินเทอร์เน็ตเพื่อโหลดแผนที่) หรือรัน `python3 -m http.server` ในโฟลเดอร์นี้ แล้วเปิด http://localhost:8000
- มือถือ: เอาโฟลเดอร์นี้ขึ้น GitHub Pages ก็เปิดจากมือถือได้ (Settings > Pages)
- กด "❓ วิธีเล่น" ในเกมเพื่ออ่านกติกา

## ปรับแต่ง
ข้อมูลมอนสเตอร์ อาวุธ เกราะ และสูตรตีของอยู่ด้านบนของ `index.html` (`MONSTERS`, `WEAPONS`, `ARMORS`, `RECIPES`)
เปลี่ยนจุดเริ่มต้นที่ `START` ความเร็วเดินที่ `SPEED`
